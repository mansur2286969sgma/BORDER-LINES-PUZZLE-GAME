# 🛂 BORDER LINES — Бюрократическая логическая головоломка о визах и границах

**BORDER LINES** — это двухмерная логическая игра-головоломка на Python 3 и Pygame, в которой единый дата-ориентированный движок правил (`RuleEngine`) управляет сразу двумя кампаниями: планированием документов путешественника (**Traveler Campaign**) и проверкой заявителей на консульском посту (**Consul Campaign**).

## 🚀 Требования и запуск

### Требования
- **Python 3.8+**
- Библиотека **Pygame** (никаких сторонних зависимостей или внешних ассетов не требуется)

### Установка
```bash
pip install -r requirements.txt
# или напрямую:
pip install pygame
```

### Запуск игры
- **Windows:** запустите `run_game.bat` двойным кликом или выполните в терминале:
  ```bash
  python main.py
  ```
- **macOS / Linux:**
  ```bash
  chmod +x run_game.sh
  ./run_game.sh
  # или напрямую:
  python3 main.py
  ```

### Флаги командной строки (для разработчиков и ревьюеров)
- `python main.py --unlock-all` — мгновенно разблокирует все уровни кампании **Traveler** и все смены кампании **Consul**.
- `python main.py --reset` — сбрасывает сохранённый прогресс, звёзды и рекорды к начальному состоянию.

### Запуск модульных тестов
```bash
python -m unittest discover -s tests -v
```

## ⚙️ Механики

1. **Единый движок правил (`RuleEngine.validate`)**:
   Обе кампании используют одну и ту же функцию валидации `RuleEngine.validate(state, destination, date) -> ValidationResult`. В режиме путешественника она проверяет собранный пакет документов на границе и выдаёт подробный отчёт, а в режиме консула — служит эталоном для оценки решений игрока.
2. **Документы и цепочки зависимостей (Prerequisites)**:
   В игре представлено **7 типов документов**:
   - *Passport* (Паспорт) — основной документ личности; требует соблюдения минимального запаса срока действия (*Passport Validity Buffer*) после дня прибытия.
   - *Entry Visa* (Въездная виза) — выдаётся для конкретной страны назначения; в ряде стран требует предварительного получения *Invitation Letter*.
   - *Invitation Letter* (Пригласительное письмо) — официальное приглашение принимающей стороны.
   - *Bank Statement* (Банковская выписка) — подтверждает наличие минимального остатка средств на счету.
   - *Vaccination Certificate* (Сертификат о вакцинации) — международное медицинское свидетельство.
   - *Travel Insurance* (Туристическая страховка) — медицинский полис с ограниченным сроком действия.
   - *Transit Permit* (Транзитное разрешение) — обязательный пропуск при следовании через транзитные узлы (например, высокогорный коридор *Tavik*).
3. **Дедлайны и бюджет (Traveler Campaign)**:
   Оформление каждого документа занимает от 1 до 3 дней и стоит денег. Игрок должен спланировать правильный порядок действий в городском бюро, чтобы не просрочить дедлайн отправления, не выйти за рамки бюджета и не допустить истечения короткоживущих справок.
4. **Консульская инспекция и флаггинг ошибок (Consul Campaign)**:
   На стол офицера ложатся бумажные карточки документов. Игрок сверяет их со справочником правил текущей смены, может кликать по подозрительным полям (несовпадение имени, истёкший срок, недостаточный запас дней паспорта, чужая страна назначения, низкий баланс, отсутствие гербовой печати) и выносит вердикт: **APPROVE** (Одобрить), **DENY** (Отказать с указанием причины) или **REQUEST MISSING DOCUMENT** (Запросить недостающий документ).

## 🗺️ Кампании

В игре используются только вымышленные страны (*Valdoria, Norwen, Keshmar, Orlanda, Tavik, Sunmere*) с дружелюбным юмористическим тоном. Весь внутриигровой текст выполнен на английском языке.

### Кампания 1: Traveler Campaign (5 уровней)
- **Level 1 — "First Trip"**: Знакомство с интерфейсом и картой; оформление первой визы из Вальдории в Норвен.
- **Level 2 — "Fresh Ink"**: Паспорт истекает слишком рано и не проходит 30-дневный буфер Норвена — необходимо сначала обновить паспорт, а затем подавать на визу.
- **Level 3 — "Tight Schedule"**: Поездка в Орланду; сжатые сроки и короткий срок действия выписок требуют точного расписания действий. *(Завершение 3-го уровня открывает кампанию Консула!)*
- **Level 4 — "Paper Trail"**: Поездка на солнечный саммит в Кешмар; виза требует предварительного *Invitation Letter*, а также вакцинации и страховки при строго ограниченном бюджете.
- **Level 5 — "Grand Route"**: Многосоставной маршрут через транзитный хаб Тавик на архипелаг Санмир с полным досье и транзитным разрешением.

### Кампания 2: Consul Campaign (5 смен — открывается после 3 уровней Traveler)
- **Shift 1 — "Morning Desk"**: Базовая проверка паспортов и виз на посту Вальдории с учётом безвизовых соглашений (*Norwen* и *Sunmere*).
- **Shift 2 — "Northern Winds"**: Пост Норвена; строгий 30-дневный запас срока паспорта, поддельные имена и забытые печати.
- **Shift 3 — "Directive 44-B"**: Внезапная министерская директива на доске объявлений Орланды — обязательный аудит банковских выписок (минимум \$200) и страховок для всех въезжающих.
- **Shift 4 — "Quarantine & Sponsors"**: Смена с таймером в порту Кешмара; проверка приглашений, сертификатов вакцинации и транзитных разрешений через Тавик.
- **Shift 5 — "Grand Archipelago Audit"**: Финальный экзамен на паромном терминале Санмира под давлением времени, где многие заявители повторяют типичные ошибки из кампании Путешественника.

## 🛠️ Особенности реализации

- **Чистый Python 3 + Pygame**: Никаких сторонних библиотек (без NumPy и т.д.) и **ни одного внешнего файла изображений или аудио**.
- **Полностью процедурная графика и анимации**: Флаги стран, континентальная карта, портреты заявителей с разной внешностью, бумажные карточки документов, гербовые печати, анимации удара штампа, плавные выдвижные панели и частицы конфетти рисуются процедурно через `pygame.draw`.
- **Процедурный синтез звука (16-bit PCM)**: Звуки кликов, удара штампа, перелистывания бумаги, монет, фанфары победы, сигнала ошибки и фоновая чиптюн-мелодия генерируются на лету с помощью стандартных модулей `math` и `array` и загружаются в `pygame.mixer.Sound(buffer=...)`. При отсутствии аудиоустройства игра корректно работает в беззвучном режиме.
- **Строгая архитектура и разделение слоёв**:
  - `game/core/` — чистая бизнес-логика и модели данных (**без импортов Pygame**), полностью покрытая `unittest` (включая BFS-солвер проходимости всех уровней).
  - `game/campaigns/` — логика сессий Traveler и Consul.
  - `game/systems/` — управление сохранениями (`os.path.expanduser` с безопасным fallback и защитой `try/except`), настройками и процедурным звуком.
  - `game/ui/` — виджеты, тема, эффекты и экраны с единым базовым классом `BaseScreen` (`on_enter`, `handle_event`, `update`, `draw`, `on_exit`).

### Как добавить новую страну или уровень без изменения кода
Благодаря дата-ориентированной архитектуре весь контент загружается из папки `data/`:
1. **Добавление страны**: откройте `data/countries.json` и добавьте новый объект в массив `"countries"`, указав `id`, `name`, координаты на карте `map_pos`, стиль флага `flag`, список требуемых документов `required_documents`, зависимости визы `visa_prerequisites` и дипломатические отношения `relations`.
2. **Добавление уровня Путешественника**: откройте `data/traveler_levels.json` и добавьте объект уровня в массив `"levels"`, задав маршрут (`origin`, `destination`, `transit_countries`), бюджет, дедлайн, стартовые документы и доступные действия (`available_actions`).
3. **Добавление смены Консула**: откройте `data/consul_shifts.json` и добавьте новую смену в массив `"shifts"`, указав страну поста, `seed`, количество заявителей, активные документы и допустимые типы ошибок (`allowed_error_types`).
